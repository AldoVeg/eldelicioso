# Fotos de los queques

Deja aquí las fotos de cada versión. El resto lo hace `npm run fotos`: las convierte a WebP liviano en `img/QUEQUES/`
y las conecta con la web (cuando la franja de ese sabor se abre, la foto aparece de fondo).

## Cómo nombrar cada foto
Usa el nombre del sabor, con o sin tildes y en mayúsculas o minúsculas; también sirven "queque piña", "keke piña", "queque de piña" o "piña (2)". Todos estos sirven:

| Sabor | Nombre de archivo (cualquiera de estos) |
|---|---|
| Novia | `novia.jpg` |
| Piña | `pina.jpg`, `piña.jpg` |
| Durazno | `durazno.jpg` |
| Arándano | `arandano.jpg` |
| Plátano | `platano.jpg` |
| Maracuyá | `maracuya.jpg` |
| Fresa con arándano | `fresa con arandano.jpg`, `fresa-arandano.jpg` |
| Zanahoria | `zanahoria.jpg` |
| Naranja | `naranja.jpg` |
| Chocolate | `chocolate.jpg` |
| Marmoleado | `marmoleado.jpg` |
| Chispas de chocolate | `chispas de chocolate.jpg`, `chispas-chocolate.jpg` |
| Vainilla | `vainilla.jpg` |
| Oreo | `oreo.jpg` |
| Coco | `coco.jpg` |
| Frutos secos | `frutos secos.jpg` |
| Higo | `higo.jpg` |
| Manzana | `manzana.jpg` |
| Limón | `limon.jpg` |
| Lúcuma | `lucuma.jpg` |

Formatos: JPG, PNG, WebP, AVIF o TIFF (las fotos del iPhone en HEIC: expórtalas antes a JPG).
Una foto por sabor; si repites el sabor, se usa la más reciente. Si agregas un sabor nuevo, escribe su nombre en el archivo
y se avisa que todavía no existe en la lista.

Esta carpeta no se sube a GitHub ni a la web: solo se publica la versión ya optimizada.
